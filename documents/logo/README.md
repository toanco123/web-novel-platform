# Logo Web Truyện — phương án A "Sách nở hoa"

## public/ — chép đè vào thư mục public/ của project (trùng tên file đang dùng)
favicon.ico (16/32/48), favicon.svg, apple-touch-icon-180x180.png,
pwa-64x64.png, pwa-192x192.png, pwa-512x512.png, maskable-icon-512x512.png, og-default.png (1200×630)
Không cần sửa index.html hay manifest.webmanifest.

## logo/ — dùng cho header, mạng xã hội, tài liệu
- logo-header(.svg/.png): biểu tượng + chữ, cho thanh header. Bản -light cho nền sáng.
- logo-horizontal(.svg/.png): có thêm dòng "ĐỌC TRUYỆN CHỮ ONLINE".
- logo-mark(.svg/.png): chỉ biểu tượng, nền trong suốt.
- og-default.svg: bản gốc của ảnh chia sẻ, sửa được.
Chữ đã chuyển thành nét vẽ (outline), không cần cài font.
